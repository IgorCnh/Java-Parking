# Java Parking System

Projeto desenvolvido em **Java** com o objetivo de simular um **software de gerenciamento de estacionamento**.

 **Status do projeto:**  
🚧 *Em construção* 🚧  
Este projeto ainda está em desenvolvimento e novas funcionalidades serão adicionadas em breve.

---

## Sobre o projeto

O **Java Parking System** é um sistema que permite gerenciar:

- Entrada e saída de veículos
- Controle de vagas disponíveis
- Registro de horários (entrada e saída)
- Cálculo de tempo estacionado
- Cálculo de tarifas
- Validação de dados e tratamento de exceções

O foco do projeto é aplicar conceitos fundamentais e intermediários de **Java**, como:
- Programação orientada a objetos (POO)
- Enumerações
- Tratamento de exceções
- Manipulação de datas (`LocalDateTime`)
- Leitura de dados via terminal
- Boas práticas de organização de código
